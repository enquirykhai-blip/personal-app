# My Space

Personal web app untuk urus tugasan harian (todo list) dan jejak tabiat (habit tracker). Semua data disimpan dalam browser (localStorage) — tiada backend atau login diperlukan.

## Ciri-ciri

- **Tugasan**: tambah, tandakan siap, kategori (peribadi/kerja/urusan/lain-lain), tarikh akhir, dan penapis (semua/belum siap/siap).
- **Tabiat**: tambah tabiat, tandakan siap untuk 7 hari terkini, dan lihat streak semasa.

## Jalankan secara tempatan

```bash
npm install
npm run dev
```

## Build untuk production

```bash
npm run build
npm run preview
```
